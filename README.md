## 本次升级：经营比率的加权汇总与口径核对

将两分组分子分母汇总后计算比率，并展示简单平均与正确加权比率差异；不直接相加平均率，零分母明确拒绝。

新增已认证的结构化录入工作台（`/operations.html`），支持批量核算、逐条结果依据、分级复核和CSV/完整JSON导出。结果由真实后端算法计算，不是预置演示数字。所有数值精确传递，不调用外部模型。

这是**只读核算**：不写库、不审批、不自动执行财务、签署、销毁或设备控制。输入条件满足不是执行授权。[算法、输入边界与接口说明](docs/OPERATIONS-REVIEW.md)。
## 企业级增强：经营报告关账治理

## 这个项目解决什么

周报、月报和管理层专题报告经常耗费大量时间在取数、对口径、解释波动和追行动项上。ReportAgent 用认证指标快照组织这些工作，生成管理摘要和差异解释草案，同时把关键判断、敏感财务信息和最终发布留给负责人。

![经营报告智能体运营中心](docs/images/reportagent-operations.png)

运营中心管理报告计划、指标新鲜度、异常状态、审阅进度和发布版本。

![经营分析师报告工作台](docs/images/reportagent-workspace.png)

分析师端聚焦当前报告的指标快照、差异解释、管理摘要、行动建议与签发责任。

## 报告流水线

`报告计划 → 指标快照 → 异常识别 → 差异解释 → 管理摘要 → 人工审阅 → 版本发布 → 行动跟踪`

主要功能包括：

- 周报、月报、专题报告计划与模板
- 经营指标定义、负责人和刷新状态
- 数据快照、波动提示与解释草稿
- 财务敏感字段按角色脱敏
- 报告审阅、签发、版本与审计记录
- 会后行动项、责任人和完成状态跟踪

`ReportReleaseGuardService` 会拦截过期指标和未经确认的敏感财务信息，确保演示中的 Agent 只能起草，不能直接发布正式经营结论。

## 输入对照与版本化快照

在既有「经营比率的加权汇总与口径核对」基础上，新增 `/comparison.html`：基准与候选两组数据都由当前真实算法重算，按编号展示新增、移除、逐字段变化和精确数值差，支持筛选、分页和全量导出。原核算入口可导出输入快照，对照页经后端完整校验后整体导入；失败不覆盖当前输入。

快照区分项目、字段契约及算法版本。建议较宽松不代表风险已下降，输入摘要不是签名；操作人和时间仅为响应元数据，不是持久化审计。本次未新增模型调用或业务写入，也不代表全系统生产认证。详见[输入对照操作与接口说明](docs/INPUT-COMPARISON.md)。
